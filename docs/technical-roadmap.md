# 技术路线

1. **建立离线样本**。准备脱敏或模拟的网络告警、Windows 事件及预期关联。覆盖重复输入、时间偏差、设备标识缺失和共享 IP。
2. **实现数据导入与存储**。计划使用 Python 处理数据，先确定事件规范和关系数据库结构，再验证事务、唯一约束、错误报告和查询索引。
3. **建立规则基线**。用主机标识和时间窗口生成可解释的候选证据，保存规则版本。使用相同样本比较不同规则的覆盖与误关联情况。
4. **接入结构化 AI 草稿**。向模型提供脱敏证据与引用 ID，校验返回字段和引用；失败时保留规则证据并交给人工复核。
5. **完成研判和复核演示**。先验证离线流程，再评估接入实际数据源的条件。记录复现输入、版本、基线、测量方法和原始结果。
