# 系统架构设计

> 设计草案，随数据样本和验证结果调整。

## 数据流

告警文件与终端事件 → 导入和校验 → 规范化与入库 → 规则关联 → 生成研判草稿 → 人工复核与归档。

导入层保留来源引用、批次信息和解析错误。统一记录事件时间、时区和导入时间。关联层返回候选事件及匹配理由。AI 层只读取脱敏后的候选证据。模型故障时，规则关联、检索和人工复核仍可使用。

## 数据实体

| 实体 | 用途及核心字段 |
| --- | --- |
| ImportBatch | 数据源、导入时间、输入标识、成功与失败计数 |
| Host | 稳定设备标识、显示名、标识可信来源 |
| Alert | 来源告警 ID、时间、来源、涉及地址、告警类型、研判状态 |
| Event | 来源事件键、设备标识、时间、通道、事件类型、原始记录引用 |
| AlertEvidence | 告警与事件的多对多关系，保存规则版本、匹配理由和关联时间 |
| Assessment | 告警外键、草稿版本、事实、推测、证据缺口、引用的证据 ID |
| Review | 草稿外键、复核时间、复核人、意见和处理结果 |

给来源记录建立唯一键。对设备标识与事件时间建立联合索引。对告警、证据、草稿和复核关系施加外键约束。IP 作为观测字段使用，设备归属以可回溯的可靠标识为依据。
